# Internal Synthesis Checklist

This checklist guides the synthesizer's **private work**; it is not an output template. Apply the mandatory `conflict-and-coverage-protocol.md` alongside it.

1. Confirm each input is about the same paper and compatible source version.
2. Map evidence and analyses to the eight Skill 1 sections.
3. Retain distinct valuable insights and eliminate duplicated restatements.
4. Check each major claim against the source where accessible.
5. Distinguish author claim, paper evidence, interpretation, and independent critique.
6. Do not decide truth by majority vote or model reputation.
7. For conflicting claims: inspect source; correct mistakes; if unresolvable, qualify or omit.
8. Do not propagate fabricated page numbers, quotations, results, or references.
9. Produce ONE report using the primary skill's existing `templates/review-template.md` format.
10. Do not include model-by-model analysis, rankings, methodology narrative, or separate final synthesis appendix.
11. Use N/A for genuinely non-applicable criteria and Not verified for unsupported claims.
12. Normalize claims across source versions, denominators and experimental settings before identifying true disagreements.
13. Resolve material conflicts as Verified / Corrected / Unresolved / Not applicable internally; do not output a status ledger.
14. Audit each important unique insight and high/medium critique for inclusion, meaningful merge, justified exclusion or unresolved verification.
15. Escalate only consequential unresolved questions with an actionable human check, in the existing report/audit.
