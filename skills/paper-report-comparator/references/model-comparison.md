# Optional multi-LLM comparison protocol

1. Ensure models have access to the **same paper version** and the same core questions.
2. Run each model independently when possible; keep outputs separate before comparison.
3. Record model name/version if known, input materials, prompt, settings (if known), and date.
4. Normalize results into: problem, claimed contribution, approach, evidence, limitations, critique, source locations.
5. Compare **correctness**, **coverage**, **grounding**, **uncertainty calibration**, and **usefulness**, not just verbosity.
6. For every substantive disagreement, inspect the underlying source and record: model A, model B, original evidence, adjudication, unresolved uncertainty.
7. Report failures as well as successes. Do not claim a model was tested unless it actually was.
8. Final conclusions belong to the human reviewer; model consensus is not proof.
